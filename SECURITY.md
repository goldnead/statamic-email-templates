# Security policy

## Supported versions

Only the latest release of this addon receives fixes, and only against the
Statamic major it targets (Statamic 6).

## Reporting a vulnerability

Do not open a public issue.

Email **info@adriangoldner.com** with:

- what the problem is and what it lets an attacker do,
- the addon and Statamic versions you saw it on,
- the smallest set of steps that reproduces it.

You will get an acknowledgement within a few days. Once a fix is released, the
CHANGELOG entry credits you unless you would rather stay anonymous.
